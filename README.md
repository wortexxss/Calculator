# Basit Hesap Makinesi

Bu proje, Java Swing istifadə edərək hazırlanmış sadə bir kalkulyatordur. İstifadəçilər iki ədəd daxil edərək toplama, çıxma, vurma və bölmə əməliyyatlarını yerinə yetirə bilərlər.

## Proqramın Xüsusiyyətləri
- İki ədədin toplanması
- İki ədədin çıxılması
- İki ədədin vurulması
- İki ədədin bölünməsi
- Qrafik interfeys (GUI) dəstəyi (Java Swing istifadə olunub)

## Tələblər
Bu proqramın işləməsi üçün aşağıdakı proqram təminatları lazımdır:
- Java Development Kit (JDK) 8 və ya daha yeni versiya
- NetBeans IDE və ya hər hansı digər Java IDE (isteğe bağlı)

## Quraşdırma və İşlətmə

1. **Kodun Yüklənməsi:**
   - Depodan kodu yükləyin və ya klonlayın.
   ```bash
   git clone https://github.com//wortexxss/Calculator/basit-hesap-makinesi.git
   ```

2. **Java-nı çalışdırın:**
   - Terminal və ya komanda sətrində aşağıdakı əmri icra edin:
   ```bash
   javac BasitHesapMakinesi.java
   java BasitHesapMakinesi
   ```

3. **Proqramın İstifadəsi:**
   - Açılan pəncərədə iki ədəd daxil edin.
   - İstədiyiniz əməliyyatı seçin (+, -, x, /).
   - Sonucu görə biləcəksiniz.

## Kod Haqqında
Bu proqram `javax.swing` kitabxanasından istifadə edərək qrafik interfeys yaradır. Əsas funksionallıq aşağıdakı metodlarla həyata keçirilir:

- **artiActionPerformed()**: Toplama əməliyyatını yerinə yetirir.
- **eksiActionPerformed()**: Çıxma əməliyyatını yerinə yetirir.
- **carpiActionPerformed()**: Vurma əməliyyatını yerinə yetirir.
- **bolmeActionPerformed()**: Bölmə əməliyyatını yerinə yetirir.
